# Política de Privacidad — MotionWall 4K

**Última actualización: 5 de octubre de 2026**

MotionWall 4K es una aplicación de fondos de pantalla estáticos y animados para Android.

Esta Política de Privacidad explica qué información puede procesar MotionWall 4K, para qué se utiliza y qué opciones tiene el usuario.

## 1. Información que podemos procesar

Dependiendo de las funciones que utilices, MotionWall 4K puede procesar:

* Identificador de usuario de Firebase.
* Nombre y dirección de correo electrónico proporcionados mediante Google Sign-In.
* Foto de perfil de Google, cuando está disponible.
* Lista de fondos favoritos.
* Información necesaria para gestionar el estado de Premium y las compras realizadas mediante Google Play.
* Información relacionada con publicidad, incluida la información que los servicios de publicidad de Google puedan utilizar de acuerdo con sus propias políticas.
* Información técnica necesaria para que funcionen los servicios de Firebase, Google Play y la aplicación.

MotionWall 4K no solicita contraseñas de Google ni almacena contraseñas de los usuarios.

## 2. Inicio de sesión con Google

MotionWall 4K permite iniciar sesión mediante Google.

El proceso utiliza los servicios de Google y Firebase Authentication. Los tokens de autenticación se utilizan para completar el proceso de autenticación y no son almacenados por MotionWall 4K como una contraseña ni guardados deliberadamente en una base de datos propia.

## 3. Cuenta anónima

La aplicación puede utilizar una cuenta anónima de Firebase para permitir determinadas funciones antes de que el usuario vincule una cuenta de Google.

Cuando el usuario vincula su cuenta de Google, se intenta conservar la información de la cuenta existente, como sus favoritos.

## 4. Favoritos

Los fondos que marques como favoritos pueden sincronizarse con Firebase Firestore para que puedas conservarlos asociados a tu cuenta.

Los datos de favoritos están asociados al identificador de tu cuenta y las reglas de seguridad de Firestore impiden que un usuario acceda a los datos de otro usuario.

## 5. Fondos de pantalla

La aplicación descarga y almacena localmente los recursos necesarios para mostrar los fondos de pantalla y permitir determinadas funciones sin conexión.

Los archivos descargados se almacenan en el almacenamiento privado de la aplicación y pueden eliminarse al borrar los datos de la aplicación o desinstalarla.

## 6. Publicidad

MotionWall 4K utiliza Google AdMob para mostrar publicidad en las cuentas que no tienen acceso a Premium.

La aplicación utiliza la plataforma de consentimiento de Google (UMP) cuando corresponde. Las solicitudes de publicidad están condicionadas por el estado de consentimiento proporcionado por UMP.

Los usuarios Premium no reciben la publicidad de la aplicación que está bloqueada por el estado Premium.

Google puede procesar información relacionada con publicidad, identificadores y actividad publicitaria conforme a sus propias políticas y configuraciones de consentimiento.

## 7. Consentimiento de publicidad

Cuando la legislación aplicable requiere obtener consentimiento para determinadas tecnologías publicitarias, MotionWall 4K utiliza el sistema de consentimiento de Google.

El usuario puede acceder a las opciones de privacidad disponibles desde la aplicación.

Las opciones disponibles pueden variar según la ubicación del usuario y los requisitos legales aplicables.

## 8. Compras y Premium

MotionWall 4K utiliza Google Play Billing para gestionar las suscripciones y compras de Premium.

La aplicación no almacena números de tarjetas bancarias ni datos completos de pago.

El procesamiento del pago se realiza mediante Google Play.

MotionWall 4K puede conservar localmente información técnica mínima necesaria para recordar temporalmente el estado de Premium y proporcionar una experiencia adecuada cuando existe una interrupción temporal de conexión.

Google Play sigue siendo la fuente de verdad para validar las compras.

## 9. Firebase

MotionWall 4K utiliza servicios de Firebase, incluidos Firebase Authentication y Cloud Firestore.

Firebase puede procesar información técnica y de cuenta necesaria para proporcionar estos servicios.

El uso de Firebase está sujeto también a las políticas de privacidad de Google.

## 10. Proveedores de servicios

La aplicación utiliza servicios de terceros para proporcionar determinadas funciones, entre ellos:

* Google Firebase / Firebase Authentication.
* Google Cloud Firestore.
* Google Credential Manager y servicios de Google para el inicio de sesión.
* Google Play Billing.
* Google AdMob.
* Google User Messaging Platform (UMP).
* Servicios utilizados para obtener recursos de fondos de pantalla.

Estos proveedores pueden procesar información de acuerdo con sus propias políticas y condiciones.

## 11. Seguridad

MotionWall 4K utiliza mecanismos de autenticación y reglas de seguridad para limitar el acceso a los datos de los usuarios.

Los datos de Firestore están protegidos mediante reglas que vinculan el acceso de cada usuario con su identificador autenticado.

No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

## 12. Eliminación de la cuenta

MotionWall 4K permite al usuario solicitar la eliminación de su cuenta desde la aplicación mediante la opción **Eliminar cuenta**.

El proceso elimina la cuenta de Firebase Authentication y los datos asociados almacenados por la aplicación en Firestore, cuando corresponda.

Después de la eliminación, el usuario puede volver a utilizar la aplicación como una cuenta nueva.

Los servicios externos pueden conservar determinados datos cuando exista una obligación legal o cuando sus propias políticas de conservación sean aplicables.

## 13. Cierre de sesión

El usuario también puede cerrar sesión sin eliminar su cuenta.

Cerrar sesión no equivale a eliminar la cuenta.

## 14. Almacenamiento local

MotionWall 4K utiliza almacenamiento local para determinadas funciones de la aplicación, como archivos descargados, cachés y la información técnica necesaria para recordar temporalmente el estado de Premium.

Los datos locales pueden eliminarse desinstalando la aplicación o borrando sus datos desde Android, según el tipo de información.

## 15. Información que no recopilamos deliberadamente

MotionWall 4K no solicita deliberadamente:

* Contraseñas de Google.
* Números completos de tarjetas bancarias.
* Datos completos de cuentas bancarias.
* Información de contacto almacenada en el teléfono sin necesidad de la función correspondiente.
* Archivos personales del almacenamiento compartido del dispositivo.

## 16. Privacidad de menores

MotionWall 4K no está diseñado específicamente para niños.

La aplicación no solicita deliberadamente información personal de menores para crear perfiles publicitarios propios.

Los servicios de terceros utilizados por la aplicación pueden aplicar sus propias políticas y restricciones relacionadas con menores.

## 17. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones de MotionWall 4K, los servicios utilizados o los requisitos legales aplicables.

Cuando se realicen cambios importantes, se actualizará la fecha de última modificación de esta página.

## 18. Tus derechos

Dependiendo de tu país o región, puedes tener derechos relacionados con tus datos personales, incluyendo derechos de acceso, eliminación, rectificación u oposición cuando sean aplicables.

Puedes utilizar las opciones disponibles dentro de la aplicación o los mecanismos proporcionados por los servicios correspondientes.

## 19. Contacto

Para consultas relacionadas con privacidad, utiliza los canales oficiales de soporte proporcionados para MotionWall 4K en la tienda o en la aplicación.
